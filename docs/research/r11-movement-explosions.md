## 骰子、落点与分岔

| 普通穿越岔路 | B3明确随机转向 | 概率是否均匀、选项是否包含掉头、同一日路径是否预先生成未知 |
| 停在岔路 | B3正文后的配图说明明确只有正好停在岔路才能选择方向 | 是落地立即选还是下次移动前选、哪些机关岔路例外未知。不能把所有普通分岔都改成永远随机 |

实现含义（推断）：至少区分穿越分岔与在分岔起步，并将指定目标移动和普通随机移动分开；给定目标不应被后续随机岔路悄悄改写。这里没有证据支持全部路线由玩家每格决定，也没有证据支持遥控固定走6格。

## 梦游与互斥状态

梦游持续2天由B1确认。C2的11领主策略明确梦游可阻止领主收取费用；11策略明确已睡着者不能使用被动防御卡。C3明确梦游角色会路过银行而不能领取存款。这些行为说明梦游不能实现为简单跳过移动，也不能只禁用出牌而保留完整经济界面。

| 行为 | 结论/证据边界 |
|---|---|
| 继续移动 | C3经过银行及C2梦游投出1点的11漏洞描述直接支持仍移动。玩家无需点GO的完整自动执行流程未取得录像；自动推进可以作为实现选择，不能标为实机已证 |
| 主动卡/防御卡 | C2通用梦游介绍禁止操作/用卡，11策略明确被动防御不可用；刚收到梦游攻击时的同命窗口仍须保留，详见第四轮 |
| 付租与收租 | 11领主专段支持梦游不能收租；仍需付租来自梦游通用介绍，缺少本轮11专属逐笔账单。不要把不能收租等同于本人免租 |
| 银行 | C3支持梦游经过银行不取钱；具体是否连存款界面/利息结算都禁用没有证据，尤其不能因此停止账户定期计息 |
| 购地/建设 | C2通用简介称禁止；尚未拿到11专属画面，应保留C级边界 |
| 骰数/车辆 | 通用页称多数作品步行，但7/8使用车辆；不能据此给11断言固定1骰或销毁车辆 |
| 冬眠/梦游/乌龟 | C2明确11通常不能共存，可以用乌龟解除队友睡眠控制。另有11同命反击梦游时乌龟残留的漏洞记录，可能与版本相关 |
| 停留/转向 | 没找到11把它们纳入上述互斥组的证据；转向是朝向操作，不能自动解释成异常状态覆盖 |
| 醒来/受伤 | 4Fun受爆炸醒来的描述不用于11；11状态清除时间、住院是否清残留梦游、日界扣减仍待实机 |

## 附身炸弹、连爆与独立后果

B1定时炸弹描述为30步内设法摆脱、可追上别人传给他，并写传统住院4天、受影响建筑降2层。计时单位是步，不能改成30天或30个人回合。C5明确10以后经过即可附身；11雪莉策略明确炸弹会替换原有神仙，避免其下回合再次请神。启动卡的11专页支持引爆选定路格周边角色身上的炸弹，送神移除沿用B1。

没有取得以下精确时序：初次拾取该步是否扣1、追上传递前后扣步、对方主动走过携弹者是否会接弹、同格多人选谁、传递是否重置倒数、香蕉/果冻/列车/传送是否计步。系列通用策略倾向传给迎面角色，不能替代11专属边界测试。

| 爆裂物 | 传统模式B1/B2 | 连爆资料 |
|---|---|---|
| 地雷 | 住院2天，威力范围内建筑降1层 | 明确引爆其他地雷、炸药 |
| 飞弹 | 住院1天，威力范围内建筑降1层 | 明确引爆地雷、炸药 |
| 定时炸弹 | 住院4天，被炸到建筑降2层 | 没有从卡表确认它与地雷相同的传播集合 |
| 炸药 | 住院8天 | 可被其他爆炸引爆；自身是否继续传播和建筑破坏未在卡表写明 |
| 量子飞弹 | 住院5天，范围建筑夷平 | 明确引爆范围内地雷、炸药 |
| 急速弹 | 向每位对手位置发弹，住院3天、建筑降1层 | 明确范围内地雷、炸药连爆；多发重叠如何累计未知 |

B5明确热斗角色遭爆炸不住院、大型地产不受爆炸影响；各爆炸改为不同程度现金损失，精确数值未知。不能把传统拆楼和住院直接附加到热斗现金伤害上。

C5免罪卡页明确11无懈能抵消爆炸住院，但使用中的车辆仍会损毁。第四轮另有武神11资料支持转移也不保车。因此医院、防御消耗、车辆损毁、建筑破坏是不同后果；阻止住院不应撤销整场爆炸。每一种炸药是否都毁车、车辆损毁与住院反应的具体先后仍未逐项实测。

## 必须保留未知的空间参数

本轮没有拿到11专属的地雷、炸药、附身炸弹、飞弹、量子飞弹精确作用半径，也没有确定半径使用道路最短距离、平面方形、圆形还是三维空间距离。A1提及在热斗攻击对面道路，提示纯道路步距未必能表达原作空间命中，但这只是设计推断。

明确排除两类搜索误命中：

- C5定时炸弹页的3×3及范围建筑夷平明确属于4Fun，不属于11。
- [Steam《大富翁10完全指南》](https://steamcommunity.com/sharedfiles/filedetails/?id=2718584880)的1×1、3×3、5×5与11×11用卡范围属于10；评论提到11不会让指南正文变成11规则。

连爆可实现事件队列与已引爆物件去重作为防死循环的工程约束；但相同角色能受几次伤、住院天数取最大/覆盖/相加、爆炸中心被清除之后的后续命中，以及是否需要等待每次防御窗口，全部仍需原版核对。任何临时半径、现金伤害或持续参数必须标注为项目假设。

## 下一次原版核验最小用例

1. 持汽车分别切1/2/3骰；穿越岔路与停在岔路后起步对照；同位置遥控、超级骰逐条记录目标高亮。
2. 梦游角色有车、有免费/无懈、有地产，走过银行、停对手地、被对手停己方地；记录GO是否自动、现金、租金与每个交互窗口。
3. 乌龟→梦游、梦游→乌龟、冬眠→乌龟与同命反击分开测试；停留、转向不预设属于互斥组。
4. 携弹剩1/2步时经过对手、香蕉、果冻和传送门，分别录每一步显示和传递归属。
5. 同层相邻路、隔墙近路、上下层叠路分开放爆裂物、角色和楼；测最远命中边界与连爆传播。
6. 有车且持无懈/转移时爆炸，分别记录反应、车辆、建筑、住院；热斗重复确认只发生对应模式后果。

本轮补齐了减骰、岔路停点例外、遥控落点、梦游银行限制、娃娃选路等证据；爆炸半径、精确时序与状态覆盖矩阵尚未达到可宣称原版复原的程度。
