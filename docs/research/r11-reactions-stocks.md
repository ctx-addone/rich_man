## 反应卡：可以确定的能力边界

| 卡名（国际版卡表） | 确认效果 | 能否当作通用盾 |
|---|---|---|
| 无懈卡（系列旧名免罪卡） | B2：免除一次任何原因导致的入狱、入院。C2 的11行：谋划/陷害可触发且可取消；梦游、冬眠均不可触发 | 不能抵挡所有攻击，更不能抵挡全部爆炸副作用 |
| 转移卡（系列旧名嫁祸卡；用户称转嫁） | B2：入狱、入院或达到一定金额的损失可转移。C2 的11行：查税/查账攻击可触发且可取消 | 金损阈值未知；不能假定所有零钱损失都触发 |
| 同命卡（系列旧名复仇卡） | B2：对梦游、冬眠、谋划的施卡者施加相同效果 | 原受害者仍承受原效果；不是反弹后自己免伤 |
| 免费卡 | B1：损失超过一定金额时给予免费机会 | 不是提前挂起的租金护盾；阈值未给 |

由 B1/B2 和 C1 可列出的最小反应矩阵：

| 原事件 | 无懈 | 转移 | 同命 | 免费 |
|---|---|---|---|---|
| 谋划导致入狱2天 | 可以，C2支持拒用 | 可以 | 可以，双方入狱 | 无对应依据 |
| 梦游2天 | 不可以 | 不可以 | 可以，双方梦游 | 无对应依据 |
| 冬眠2天 | 不可以 | 不可以 | 可以，双方冬眠 | 无对应依据 |
| 爆炸导致住院 | 可以 | 可以 | 无对应依据 | 无对应依据 |
| 查账金损 | 无对应依据 | 可以，C2支持拒用 | 无对应依据 | C3支持防御，阈值未知 |
| 达到触发门槛的费用 | 无对应依据 | 可以，类别仍需核验 | 无对应依据 | 可以，类别仍需核验 |

“无对应依据”表示本轮没有证据，不能当作已实测不允许。C3 的饭店页明确10/11热斗租金仍能用免费或转移；不得因此把住店本身也认定为免除。购物、乐透、事件、领主抽成是否均有同样窗口仍需分类确认。

C1 明确：处于梦游或冬眠的角色不能使用被动防御；爆炸住院或谋划入狱可接续控制。这里的“睡着后禁用”和“刚收到睡眠攻击时可同命”是不同时间点。不能先设置梦游标记再据此拒绝该次同命反应。

C2 明确11代无懈可以免爆炸或野狗造成的住院，**载具仍可能被爆炸毁坏**；C3 的11专属武神页同时支持无懈/转移挡住院但不保载具。它们不是撤销整个爆炸事件的操作。

## 反应流程中仍不得擅定的部分

1. 多张合格防御卡的呈现顺序、能否直接选择任一张。C2 通用介绍有无懈优先，但没有为11提供独立流程；复仇条目把某些顺序明确放在4/7或4Fun，不能移植。
2. 转移只能一次、第三方能否再用无懈/免费/同命等，C2 有系列通则，尚无11专属逐步证据。
3. 转移目标能否选择施卡者/队友、目标距离、在医院/监狱的角色能否选中，以及无人可转移时是否耗卡。
4. 同命反击是否还能被再次反击、原施卡者已有睡眠时如何处理。
5. 触发阈值是否按物价缩放、是大于还是大于等于、连爆金损逐次比较还是合并比较。
6. 免费/转移/无懈的消耗与能力奖励、破产、住院、载具销毁的先后顺序。

实现建议（非原作内部实现断言）：先生成待结算事件，再筛选当前合格反应；以卡的实际语义修改住院、金损或新增同命效果；最后继续建筑与载具等独立后果。未知规则必须保留可替换配置与审计标记，不能写成“原版已证”。

## 银行、费用与破产：保留未知

| 问题 | 本轮结论 |
|---|---|
| 银行利率与结算周期 | A1只写月结。C4百科写10代后20天/回合，Steam用户却写15回合，存在冲突；不得选一个作为确定规则 |
| 股票买卖费用 | 没有取得11代手续费/税率证据；0费用同样不是已证明事实 |
| 成交金额与取整 | 图有两位小数，但账户取整、买卖滑点、清算价均未知 |
| 行情刷新 | 未证每个玩家回合、全局一天或开市时刷新；不得把任何一种标成还原 |
| 交易时机 | 入口存在，具体掷骰前后/睡眠/住院中是否可用未知 |
| 现金不足 | 自动使用存款、强制卖股、卖地产的触发顺序均未取得11专属证据 |
| 破产判断 | 资金不足或总资产不足、是否提供主动补救窗口未知 |
| 破产后资产归属 | 股票变现价、产权释放/接收、队友或债权人继承不能擅定 |

## 最小补验清单

1. 同时持有无懈/转移/同命，分别接受谋划、梦游和冬眠；录下所有按钮、拒用、目标与最终状态。
2. 有车角色在清醒/梦游/冬眠时分别遇地雷、飞弹；记录防御窗口、车、建筑和住院四条结果。
3. 金损从阈值两侧测试，并区分查账、租金、酒店、商店、事件、热斗爆炸；不猜阈值。
4. 同一股连续买卖、换人回合、跨日，观察可交易量是否重置及账户精确差额。
5. 在现金不足但有存款/持股/地产三种状态下分别制造债务，录完整清偿界面与破产结果。
6. 记录第15、20天与跨月银行结算，核对利率、取整以及非现金收入入账账户。

本轮结果是明确能力边界、真实股票目录和待验清单，不表示行情公式、费用、破产清算或反应优先级已还原。
