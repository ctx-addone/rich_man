# 道路—地块—建筑迁移合同（R1基础）

状态：模型合同已实现，尚未接入旧版主场景。不能据此宣称已完成地图或医院/监狱还原。

## 数据责任

- `scripts/model/board_model.gd`：只处理道路、矩形占地、显式临街关联和事件检索；不内置未核实的11代价格/滞留天数。
- 道路：稳定字符串ID、整数世界格坐标、出边、道路事件引用。出边可有方向性，方便机关；远距离连接不由模型擅自判作地铁或奖励。
- 建筑地块：ID、占地矩形、临街路格列表、类别、建筑类型、产权、等级、触发事件和规则证据ID。4×4是用户要求支持的占地样例，不是断言原作全部大型地块均为4×4。
- 事件：经过 `pass`、停留 `stop`、离开服务 `leave_service`、回合开始 `turn_start`、轮结束 `round_end` 必须区分。地产收费规则与银行经过交互不能共用一个“所有格落地结算”。
- 同一建筑所有临街格查到同一个产权对象；单次事件返回建筑ID去重。收费执行器还须以事件ID防重放，后续接入时验证。

## 几何约束

道路不能穿过建筑占地，建筑不能互相重叠；临街节点须紧邻矩形某一侧，斜对角不算。显式配置的临街节点决定触发，而非“附近所有像素”。无效配置整体拒绝，保留上一份有效地图。
