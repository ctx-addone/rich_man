# R11 特殊服务规则核对（第9轮）

核对日期：2026-11-08。目标为 Steam PC 国际版《大富翁11》的简体中文玩法。本文补充第8轮 [自动操作、保存与事件研究](https://dcncd5jl63xs.feishu.cn/wiki/WYpkwVJGDixITnkoebjczuE8nDd)，只记录研究，不代表全部系统已实现。

证据等级：A＝官方或可辨识的原作说明；B＝同期PC实玩评测/图文攻略；C＝明确涉及11代的社区记录；U＝本轮未核定。部分 Fandom、巴哈页面直接打开返回 402 / Cache miss，本轮所记内容来自搜索服务返回的完整索引段落，不能当成已经逐帧核验原作画面。原图检索找到同期评测的乐透、魔法屋截图入口，但未取得足够可读的规则画面，因此不据此升级证据。

不得采用4代的每月15日和1,000票价冒充11规则；也不得把真实彩票的号码范围带入游戏。当前可把5,000与15天作为有C线索的候选基线，号码、奖池和分奖先集中到明确命名的测试配置。若实现允许重复号码并均分奖池，那是工程测试规则，尚无11证据。

圆圆的社区条目还明确购彩会触发其追加损失能力，不能简单把购彩视为免受所有被动影响的资金转移；此处留作后续领主模式接口。[圆圆](https://richman.fandom.com/zh/wiki/圓圓?variant=zh-my)

## 魔法屋

11的处理顺序为玩家先选效果，再由魔女随机选择条件；模式不同会替换部分效果。不能直接搬用4代先给条件再选效果的顺序。[魔法屋11专段](https://richman.fandom.com/zh/wiki/魔法屋)（C）

效果与排除对象主要来自 [11策略](https://richman.fandom.com/zh/wiki/大富翁11/策略?variant=zh-hans)，得3卡的同期佐证见 [新手教学](https://www.entertainment14.net/blog/post/110982643-大富翁-11-richman-11-新手圖文教學)。索引正文还明确：领主入狱、住院、度假等从地图消失时，不受魔法屋影响。可据此优先排除这类对象；对普通玩家的全部状态矩阵仍需实机核验。

### 条件与资格

| 条件/边界 | 证据 | 实现注意 |
|---|---|---|
| 驾驶汽车、总资产最多、地产最多 | C：11策略直接举例 | “最多”并列是否全部选中、资产估值组成U |
| 男性、女性 | C：[Steam个人评测](https://steamcommunity.com/profiles/76561198826143376/reviews/)及[2022巴哈11挑战帖](https://forum.gamer.com.tw/Co.php?bPage=0&bsn=972&sn=17220&subbsn=1) | 应用显式角色资料，不从立绘或名字猜测 |
| 开局尚未登场角色 | C：巴哈挑战帖说未在场队友不会受到效果 | 单独处理尚未登场和已失能状态 |
| 一次影响多人 | C：上述Steam玩家41次记录中包括多角色同时受影响 | 不应把每个条件都化为随机挑一人 |
| 全部条件表、权重、空集合重抽、并列裁决 | U | 允许以可替换测试策略实现，但要在日志及文档说明 |

卡片半数的随机损失说明、魔法屋顺序以及资格应各自验证。不能用某条经验帖的“约12%”推导性别条件权重；该数字不是可复现的规则表。

## 随机商店

1. 同期游民PC评测明确出售卡牌随机，并描述难以买到特定卡。它证明随机货品，未证明每次查询、每日或每次进入的刷新规则。[游民评测](https://www.gamersky.com/review/202210/1528427.shtml)（B）
2. 2024-04-27的11攻略明确称商店只能购买3张；天赋、书店的额外卡可使离店展示超过3张。这支持购买配额3，**不支持仅展示3种货品**。[贴吧11攻略](https://tieba.baidu.com/p/8995417048)（C）
3. 货池全集、展示格数、同卡库存、抽样是否有放回、多人共享库存、离店再进刷新仍U。4Fun随机9件的评论描述不能用作11的证据。原有研究所专属卡等排除规则应继续单独维护。
4. 同一到访只生成一份货单，UI刷新、AI读取和价格查询不重新抽样，是当前工程确定性保障；它不是已证明的原作刷新公式。存档应保存该货单、已购次数和库存。

## 神仙循环

游民PC评测在200天对局中观察到反复遭遇坏神和好神，支持长局存在持续遭遇，仍不能区分自然离身回落、固定周期刷新、触发生成或请神来源。[游民评测](https://www.gamersky.com/review/202210/1528427.shtml)（B）

本轮“刷新、消失、重新”定向检索没有得到11原作的自然循环周期、落点、数量和去重算法。领主雪莉无神时主动请神属于领主能力，不能当成全地图循环机制。补足耗尽神仙的冷却重生可作为测试模型，但其冷却天数、全局回合触发、排除地上/附身同ID以及禁止与玩家重叠都属于工程配置。绿色清障或机器娃娃清除后的即时回归也不能擅自宣称为11规则。

## 下一轮线索：新闻与神秘人

**新闻**：官方站确认传统地图有新闻，但本轮未找到11完整事件目录和可读原图。11策略提到事件格会丢3张卡或被偷2张卡，不能据此认定它们属于全局新闻。应保持“新闻”和“随机事件格”两个来源分类。[官方站](https://rmxi.softstargames.com.tw/)、[11策略](https://richman.fandom.com/zh/wiki/大富翁11/策略?variant=zh-sg)

**神秘人**：同期新手教学确认能以很低价格买实用卡（B）；Steam上2022-12-28的11实玩评测进一步说出现位置随机、货品固定，可反复用遥控骰子停在其处购买路障和遥控骰子（C）。这提供固定基础货池的线索，但“随机出现/流动商人”不等于已证明每个回合沿路移动。[新手教学](https://www.entertainment14.net/blog/post/110982643-大富翁-11-richman-11-新手圖文教學)、[Steam11评测](https://steamcommunity.com/app/2074800/reviews/?browsefilter=toprated&l=tchinese&snr=1_5_100010_)

仍需核定：全部货品、折扣倍率、每访购买配额、经过或停留触发、补货/重定位时机、数量与持续时间。书店离开神秘人时的赠卡可以复用离店事件，但不能把神秘人直接画成固定商店格就宣称完成。

## 实施边界与验证建议

- 乐透经过服务应暂停并保留剩余步数；购票或离开后继续移动，最终停留不可再购买一遍。
- 魔法屋先提交效果，再抽条件和展示对象；候选效果、对象资格与测试规则分别配置。
- 乐透票据、开奖日和奖池、商店当前货单、待处理魔法屋与神仙冷却都进入存档；读档不偷偷重新随机。
- GM可设置开奖号码/推进开奖和指定魔法条件以覆盖零对象、多对象、破产、手牌溢出等测试；这些是测试能力，不是原作规则证据。
- 本轮停止继续扩展检索；缺口保留U，不用跨代规则或没有看到的截图填补。
