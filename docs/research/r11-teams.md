# R11 传统自由组队：规则核对与边界（第10轮）

研究日期：2026-11-08。目标为国际 Steam PC 版《大富翁11》的传统地图、自由比赛。A＝官方；B＝11同期攻略/实玩评测；C＝明确涉及11的社区记录；U＝尚未核定。挑战模式证据标注其模式，不能把领主技能当成普通组队规则。本文不代表已实现内容。

## 经济、产权与胜负

### 个人资金与团队总资产

官方把比赛结束时的胜者描述为队伍，并没有说现金、存款、股票或卡牌改为共享池。11社区策略建议用均贫、均富和查账等卡调配队友现金；巴哈讨论还提到富队友缺少相关卡时无法把钱调给别人。这些支持个人资金独立、通过规则转移的模型。[11策略](https://richman.fandom.com/zh/wiki/大富翁11/策略?variant=zh-hans)、[2022讨论](https://forum.gamer.com.tw/Co.php?bsn=972&sn=17229)（C）

可以先按个人资产持有、队伍汇总比较来建模。团队汇总资产的精确估值、并列名次、破产成员是否参与最终显示、所有人同一队是否允许开局仍U。工程可拒绝没有对抗方的开局并保留并列赢家，这必须标为测试约定。

队伍仍有一名未破产成员时，不应把该队直接判负；只剩同一支存活队伍时应按团队结束比赛，而不是逼剩余队友互相淘汰。这是对官方队伍胜负描述的直接实现解释。到期净资产中如何算股票、地产、未兑现收益继续沿独立经济研究，不因为加入组队就声称估值已核验。

### 升级与协同

应把执行者和地主分开记录：执行者负责付款与操作合法性，地主保有建筑；队友不能凭一次升级自动取得地契。现有证据没有证明任何人可直接花队友现金，也未证明升级会自动请求队友补足费用。

以下仍U，暂不能将“己方”简单替换成同一地主集合：

- 同街道的住宅加成是否统计队友产权。
- 连锁店数量是否跨队友累计，跨街/跨图范围及公式。
- 可否替队友从空地选择建筑类型、改建类型、研究内容；“可升级”不等于所有地主菜单权限开放。
- 升级受衰神影响时看行动者还是地主；免费升级天赋/神仙是否作用于队友地产。
- 升级次数、每级价格、特定建筑和破产地主的可协助资格。

没有证据前，按个人地主统计街道/连锁数量并集中为可替换策略，比声称团队连锁已还原更准确。该选择是工程默认，不是原作反证。

## 大型建筑的队伍关系

下列直接说明来自 [游侠11大型建筑页](https://gl.ali213.net/html/2022-10/934689_21.html)（2022-10-20，B）。本轮直接读取了正文，不依靠建筑名称猜效果。

| 建筑 | 队伍处理依据 | U与实现边界 |
|---|---|---|
| 商业中心 | 对手停留收费；同队免租基线适用 | 队友不应进入收费转盘；非收租特殊作用没有证据 |
| 大饭店 | 强制对手住店并收费 | 队友不应作为普通敌方住店目标；自愿入住规则U |
| 地产公司 | 传统降低己方应付租金，热斗降低己方爆炸金钱伤害 | 文案支持团队受益；多栋不同队友地产公司的叠加、上限和失效条件U |
| 书店 | 我方成员离开商店或神秘人可获赠卡，等级影响概率 | 支持离店队友获得收益；赠卡数、每栋独立判定、上限与概率另见经济研究，不因团队化自动核定 |
| 能源中心 | 增加对手购卡支出；到达建筑可获得收入 | “对手”应按敌队判断。收入只给地主还是到访队友也可领取U，不能从团队书店类推 |
| 研究所 | 地主可选卡片研究，等级扩展可研究内容 | [研究所社区页](https://richman.fandom.com/zh/wiki/研究所)有“10代起”队友可加盖但拿不到卡的概括，只作跨代线索，11独立核验仍U |
| 公园 | 公益/无攻击性建筑 | 未找到额外团队收益 |

11策略中的能源中心“帮助队友生存”随后明确使用资金调配卡，不足以证明队友停在能源中心也直接领钱。不要用战术总结替代触发对象的证据。

## 卡牌目标：按卡核对，不能统一排除队友

完整首发卡表及原图出处见 卡牌研究（本地 `docs/research/r11-cards-characters.md`）。原表存在“己方”“对手”“角色”“全部角色”等不同文字，目标判定必须分别维护。文字“对手”与社区实际可选队友之间也有个别冲突，需要按卡保留例外。

| 卡牌/效果 | 团队证据 | 建模结论与边界 |
|---|---|---|
| 乌龟、转向 | 11策略明确用于支援队友，乌龟可解除队友梦游/睡眠 | 队友可作为目标（C）；距离、失能资格继续按各卡核定 |
| 停留 | 2023巴哈攻略明确对队友使用，让其留在己方地产升级 | 队友可作为目标（C）；原地再触发的完整时序不能仅凭此段重写 |
| 均贫、均富、查账 | 11策略用来给队友调配资金 | 支持通过这些卡影响队友（C）。查账方向是施卡者收钱，不应凭“调配”改成任意送款 |
| 拾取 | [拾取/抢夺卡社区页](https://richman.fandom.com/zh/wiki/搶奪卡)明确11可让队友偷路德维希以触发团队赠卡 | 明确友方例外（C），即使首发表写“指定对手”也不能直接禁止 |
| 送神 | 首发表指定周围角色；11实玩简介也列己方可用 | 支持友方去坏神；金贝贝等角色免疫需单独判定，不能以团队替代天赋判断 |
| 冬眠、转移 | [2025困难怼怼实玩视频简介](https://www.bilibili.com/video/BV13LkrBkEyH/)称部分时候可对队友使用 | C线索，受领主限制语境影响；自由比赛完整合法性矩阵U |
| 梦游、谋划 | 首发表指定周围对手 | 缺少明确队友可选佐证。敌方目标作为候选规则，不能推导所有异常状态牌都禁止队友 |
| 机器工人、辉煌 | 首发表使用己方地产措辞 | 团队包含关系可作为候选，但11队友目标与辉煌标记究竟附着团队/角色/地产、转让后行为U |
| 窘困、灾祸、急速弹 | 首发表指定所有对手地产/各对手 | 目标集合应区分敌队；飞弹落点周围的后续爆炸仍可能误伤友方，不能把选敌目标等同于友伤豁免 |
| 怪兽、涨价、停业 | 选指定街道，不是直接选敌人 | 不应未经证据过滤街道内的友方建筑；原作混合地主作用集合仍U |
| 地雷、炸药、飞弹、香蕉皮、果冻墙等 | 同期图文明确谨防误伤本人/队友 | 保留路面/范围触发；不能统一做队友穿透或爆炸免疫 |

上述实玩视频没有逐帧核验，仅读取作者简介；“己方可用”不一定逐项证明所有己方角色均可选，也可能包含只对自己的卡（如请神/载具）。因此机车、汽车、请神不能仅凭该概括扩成可向任意队友施放。

魔法屋条件、随机事件、神仙入场和被动反应也需单独做团队审计：魔法屋按条件选中多人，不应自动排除队友；财神/穷神入场受款集合、土地公掠夺己方地契等尚需原作逐条证据。

## 破产、继承和共同资金的缺口

神秘博士困难能力会接收破产角色的地产与卡牌，已由同期图文和PC社区实玩记录相互印证；这是**指定领主能力**，不是自由组队的一般继承制度。[11游戏图文攻略](https://www.entertainment14.net/blog/post/110982608-大富翁-11-richman-11-遊戲圖文攻略)、[2023巴哈攻略](https://forum.gamer.com.tw/Co.php?bsn=00972&sn=17276)

本轮未取得自由组队破产后地产、股票和卡牌究竟释放、转给债权人、交给队友还是逐项处置的可靠规则。也未证明共同钱包、自动代偿、主动赠款界面、队友共同背债或复活。先保留明确标注的原型清偿规则，不增添没有来源的继承奖励。

NS评测的乞丐描述表明破产队友不一定完全从地图互动消失；PC自由组队的乞丐移动、讨款、队友豁免及破产成员是否在胜利画面列为胜者仍U。程序内部将破产者从主动行动队列移除是当前测试模型，不能据此宣称已还原原作破产后全部玩法。

## 本轮验收建议与证据限制

1. 用A/B证据支持的队伍关系完成2v2、2v1v1、纯单人队；逐次检查收租对象、队友升级付款人和地主不变。
2. 大建筑分别验证队友书店/地产公司收益、敌方能源加价，以及友方酒店不强制入住；共享资金与队友能源收入保持明确测试配置。
3. 以乌龟、停留、拾取作为友方目标用例，以全体敌方牌和爆炸友伤作为两个不同用例，不用一个敌我布尔值替代整个目标系统。
4. 验证队友先破产但团队未输、只余一个存活队伍结束、到期按队伍资产结算；并列和破产成员胜者显示明确注明工程约定。
5. 搜索返回的聚合AI文章、10/4Fun攻略和NS专属体验不作为PC数值依据。部分Fandom/巴哈内容来自搜索索引，非当前安装版本实机；未知项不填旧代规则。
