# R11 医院、监狱出口与设施图例核对

核对日期：2026-11-08。目标为 Steam PC 国际版《大富翁11》的传统地图，优先骑士庄园。本文件只记录公开证据与待核验项，不修改游戏规则。A＝官方文字或可直接读到的原作界面；B＝明确11代的实玩图证；C＝明确11代的一手玩家叙述；U＝本轮未核定。地图截图能证明静态布局，不能独立证明出院计时、方向或触发顺序。

## 当前能确定到哪里

骑士庄园的医院、监狱与固定道路区域存在联系，不能把“出院一律回到受伤原位置”标成已还原规则。KillKill龍 的《大富翁11困难领主雪莉攻略》明确以骑士庄园为地图，介绍在医院、监狱连接商店的区域放置定时炸弹控制领主；这是出口区域可预测的第一手策略证据。视频发布于2024-05-02；本轮读取的是作者简介，**未逐帧观看出院录像**。[B站作者原页](https://www.bilibili.com/video/BV1hw4m1C7Tm/)

同一作者在《大富翁11攻略》讨论中描述骑士庄园左侧医院、监狱与商店相连，并分别介绍雪国列车、天使岛和不夜天的医院/监狱周边商店。该页面直接打开返回403，本轮使用搜索工具返回的完整索引段落。由于两处同作者，不能算两个独立交叉验证样本。[贴吧攻略第2页](https://youhua.baidu.com/p/8995417048?pn=2)

墨谈墨话2022-11-22实玩文章中的原作小地图画面右上写明“骑士庄园”。图中左上两条末端支线旁分别有青色心形、灰色栅栏图形，可与上述医院/监狱区域叙述对应；但这张静态图不含图例文字，具体功能映射仍标为图形推断。画面下端被地图窗口裁切，不能将它冒充完整102格拓扑。[文章及图注](https://game.3loumao.org/153167078) · [原始小地图图片](https://imgheybox.max-c.com/web/bbs/2022/11/21/189e6597a2de007e8887761a642843ed/thumb.jpeg)

## 入院、出院规则表

| 问题 | 本轮证据与结论 | 等级 | 不可擅自补全的内容 |
| --- | --- | --- | --- |
| 医院/监狱是否有固定出口区域 | 骑士庄园攻略可通过医院/监狱与商店连接区域反复拦截领主；静态小地图存在两条特殊端部支线 | C＋B静态对应 | 精确出口节点ID、医院与监狱是否分别占独立可走格 |
| 是否回到受伤/被捕原点 | 没有找到11代支持一律回原点的证据；固定区域拦截策略与这种统一规则不相符 | U；反证性推断 | 不能将现有 `return_pos` 作为原版通则；其它消失状态也不能一起改 |
| 出院后朝向 | 未取得出院前后连续帧 | U | 固定朝向、沿入院前方向、随机选边或玩家选边均未核定 |
| 出口是否就是旁边的加钱格 | 图上两个特殊末端附近可见加钱标记，但不存在计步过程 | U | 出口重定位是否触发加钱；第一步是否从该格起算 |
| 最后一日停留何时结束 | 未取得带剩余天数、轮次和掷骰按钮的连续画面 | U | 回合开始或结束释放；释放当次是否还能掷骰；是否额外消耗一次行动 |
| 住院/坐牢时是否在道路上 | 11攻略将住院、坐牢描述为消失状态；不等于删除角色产权或退出比赛 | C | 渲染位置、碰撞参与、路面技能目标资格仍需分别核定 |
| 自然释放与其他释放原因 | 原作存在出院/出狱事件钩子：乌咪出狱获得传送卡，章鱼王以其他人释放触发能力 | A界面文字转录 | GM只是测试命令；自然释放/事件提前释放是否共用全部副作用未核定 |
| 住院费、入狱费、赎金 | 未找到11代明确收费规则 | U | 不得写成收费为0的已确认规则，也不得引入4代保释金额 |

出院/出狱事件钩子来自同期攻略转录的原作天赋说明，可证明“释放”应是独立状态事件，不能证明释放路格或先后顺序。[游侠攻略组原帖](https://game.ali213.net/thread-7084395-1-1.html)；章鱼王说明见[同期图文教学存档](https://www.entertainment14.net/blog/post/110982643-大富翁-11-richman-11-新手圖文教學)。

## 设施与地图图形

官方 Steam 页面将银行、乐透、商店、新闻、魔法屋称为由道路连接的功能地图格，并明确经过银行可存取款、进入商店用现金购卡。它没有承诺所有设施采用相同的旁路建筑结构，也没有提供医院/监狱出口图例。[Steam官方介绍](https://store.steampowered.com/app/2074800/11/?l=schinese)

下表以缓存小地图和局部街景的**实际可见形状**为基础。功能候选与位置必须保留证据等级；不能仅凭图标像什么就写成已完成还原。

| 功能 | 图上可见图形/放置方式 | 触发及费用可确认部分 | 当前未确认部分 |
| --- | --- | --- | --- |
| 银行 | 蓝圆底单卡/银行卡轮廓为候选；不能因为“卡片”外形就标成卡牌商店 | A：经过可存取；两份银行UI截图可读存款/取款界面 | UI遮住脚下触发格，图标确切映射仍U；手续费规则 |
| 乐透 | 蓝圆底1/2/3数字球；新图在乐透界面左下同时露出相同道路图案 | B：11代经过格可购票；A原图读数：号码01～30、物价1时每注1,500 | 1,500是否受角色/版本影响；此前C级5,000线索与此冲突，不应保留为已确认基础价 |
| 魔法屋 | 紫圆底五角星图形为候选 | A：官方确认功能地图格；第9轮核对了选效果后随机条件 | 该图标的官方图例、服务费和触发距离 |
| 卡牌商店 | 青蓝圆底店面/货架格栅轮廓为候选；与地产方形占位分开 | A：现金购卡，有限数量；B：11评测称出售卡片随机 | 缺少脚下图标与商店UI同帧直接对应；不同卡种价格及倍率 |
| 小游戏 | 蓝圆底游戏手柄图形明显；处于连接路线中 | B：存在接金币等小游戏；一手实玩描述“小游戏格” | 付费/奖励完整公式、所有玩家参与资格、该候选图标是否通用 |
| 医院 | 青色心形位于左上末端支线旁；院区绘图与道路端部应分别核验 | C：骑士庄园出院区域靠近商店，可用于拦截 | 确切路格、第一步、释放计时、费用 |
| 监狱 | 灰色栅栏图形位于另一末端支线旁 | C：骑士庄园出狱区域与商店形成运营区 | 与医院相同，不可从医院规则直接复制 |

乐透与商店文字证据来自2022-10-19的PC实玩评测，不把4代的停留购票套到11代。[游民评测](https://www.gamersky.com/review/202210/1528427.shtml)

局部街景图可直接看到：常规道路是灰色分格带，地产牌与建筑占位在路旁，部分功能标记则绘在道路格上。因此制作地图资料时应将**路格触发点、地产占地、设施视觉锚点**分开记录，不能把每个可见建筑都当作路线上的一个格。这是数据建模建议，不代表已拿到原作内部数据。[局部街景原图](https://imgheybox.max-c.com/web/bbs/2022/11/21/0cc6a27062e27123fa2430d9c10b04d6/thumb.jpeg)

### 第二作者的原作UI交叉证据

水子哥综合游戏室2022-10-24文章提供另一组PC原作截图。`second-author-map.jpg` 标题为“不夜天”，**不是骑士庄园缺片**。它重复出现心形、栅栏、青色店面、数字球、蓝色单卡、手柄和紫星图形，可作跨图图形一致性参考；不足以完成所有功能映射。[第二作者文章](https://game.3loumao.org/629956963)

`lottery-labelled.jpg` 的界面可直接读到01～30号、每注1,500、物价1、当期奖金30,000；左下背景同时显示1/2/3数字球道路图形。这比第9轮使用的5,000社区文字线索更直接，但只证明该局面显示值，尚不能推出所有版本/角色下固定票价。[乐透原图](https://imgheybox.max-c.com/web/bbs/2022/10/24/5680ce70c9f440b14974b3382c39b0ac/thumb.jpeg)

`magic-labelled.jpg` 可读到多项效果，其中拆建筑的表述是“随机摧毁1栋建筑”。当前测试实现中“所有符合条件角色的全部地产各降1级”不能因这张图升级为原版已确认规则；如何从条件对象中选择那一栋、摧毁到空地还是减层仍需再核验。[魔法屋原图](https://imgheybox.max-c.com/web/bbs/2022/10/24/062c3aa034d4cd7893e6187fcf62922a/thumb.jpeg)

**版本冲突处置：**以上图证来自2022年首发时期，未显示可核对的完整构建号，不能静默当作当前最新版参数。它足以指出现有测试号码1～10、票价5,000与原作该版本UI不一致，以及全体地产降层与“随机1栋”的粒度差异；本次仅登记冲突，不改代码、不自动替换数值。后续应取得目标版本同界面的实机证据，再明确选择首发版本基线还是当前版本基线。

## 提供给实现方的字段需求

以下是研究接口建议；本轮不改代码，不填猜测坐标。

| 字段/概念 | 用途 | 当前值应如何处理 |
| --- | --- | --- |
| `map_id`、`facility_id`、`kind` | 将医院与监狱规则绑定具体地图，支持多实例 | 每张图独立，不能用全局唯一“医院位置”覆盖所有图 |
| `visual_anchor` | 院区/监狱模型绘制位置 | 与可走道路节点分开 |
| `exit_road_id` | 从消失状态返回路网的目标节点 | 骑士庄园有固定出口区域线索；精确节点仍留空或明确TEST |
| `exit_next_road_id` 或出口允许方向 | 释放后的第一条道路边 | U，需连续视频；不能随意沿用入院前 `previous` |
| `release_timing`、`release_consumes_action` | 恢复行动与停留天数的边界 | U，如当前实现必须选择，应集中命名PROVISIONAL |
| `arrival_trigger_policy` | 释放落在出口时是否触发道具/加钱/商店等 | U，不应默认按正常走一步处理 |
| `origin_pos`、`origin_previous` | 保存入院前上下文、兼容旧存档或其他状态 | 可保留，但不能同时充当已确认的出院落点 |
| `evidence_refs`、`evidence_level` | 每个出口字段可追溯到原图或连续视频 | 原图坐标只作读图索引，不是游戏逻辑坐标 |

下一项最有价值的核验是：骑士庄园同一录像中记录入院前路格、入院剩余天数、天数归零、释放落点、掷骰按钮状态以及第一次前进方向。医院、监狱各至少一段，再分别核对中途入院与自身回合外入院；在此之前不将任一测试时序称为11原版规则。

## 明确排除的误用

- 搜索结果中的17173《大富翁Online事件点》属于2012年Online，不能用来证明11代出院规则。[排除来源](https://newgame.17173.com/news/12102012/122347639.shtml)
- 巴哈“4代休息点”与Steam《大富翁10》评测即使讨论医院门口、分支选择，也不作为11代方向证据。
- IGN评测提到医院/监狱门口无限埋雷的段落是在回顾4代，不能截去上下文当作11代实测。[需保留语境的来源](https://www.taptap.cn/moment/665877492036274889)
- “不夜天出门右拐到商店”是另一张地图的一手策略叙述，不代表骑士庄园固定右转，更不代表所有地图共用朝向。
