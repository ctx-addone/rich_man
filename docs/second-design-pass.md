# 第二轮游戏设计与优化：讨论基线

日期：2026-11-08，面向 v0.17 当前实现。用户要求先推送当前检查点，再进入第二轮设计与优化；具体提交与推送结果以本轮发布记录为准。R1—R17 是内部实施批次，与用户所说的“第二轮设计”分别计数。下列优先项是后续工作，不代表已经完成。

## 当前可试玩基线

Godot 2D、单机热座及基础电脑、菜单到终局流程已具备；骑士庄园有 102 个道路节点、104 条边、58 块小地产和 4 块大地产。已有队伍、多入口产权、银行股票、卡牌神仙、新闻子集和四种小游戏。R16 新增资源设置、有限期/无限期、日历与分类物价；R17 接入独立道路神秘人、狗、破产乞丐及交易/反应/存档流程。

大量数值和边界仍是 TEST。已有回归与整局证据见 `docs/round-16-report.md`、`docs/round-17-npc-review.md` 及各轮测试目录；它们验证当前规则能运行，不证明与原作完全一致。本文件只更新设计提纲，不重复宣称执行这些测试。

## 建议的设计顺序

| 优先级 | 设计议题 | 需要回答的问题 | 验收方式 |
| --- | --- | --- | --- |
| P0 | 逐卡价格与经济口径 | 正规商店仍是每张 300 的测试价，神秘人已有实机 1000，导致廉价关系倒置。先补哪些同名卡报价？哪些修正属于物价、角色或建筑？ | 先形成有来源的逐卡价表；区分 `transfer` 转移与 `reverse` 转向。报价、现金扣款、AI预算与读档一致；同卡在普通角色/糖糖、不同物价下分别核对。不为让 NPC 看起来便宜而捏造价格 |
| P0 | 热座交接与操作反馈 | 行动者、受击者、小游戏操作席、交易者切换是否清楚？暂停和读档后是否知道如何继续？ | 实际完成四人热座一局，覆盖商人→地产/商店、反制→原行动者、小游戏→棋盘、途中读档。交接前隐藏应保密手牌；无误触、重复付款、交接卡死；地图、角色、按钮在目标窗口尺寸内可见 |
| P1 | 分类物价与整局节奏 | 地价、建设、现金格、乐透、利息和清偿仍有未核参数；新局较高资源是否使购地、储蓄与卡牌选择失去压力？ | 每类收支单独列基础值、倍率和取整，未证项标 TEST；余额转移守恒，账单只缩放一次。相同地图/种子/席位条件记录总时长、手动点击、等待、破产日与胜负，对比改动前后，不只看能否结束 |
| P1 | NPC 规则与可读性 | 神秘人途经、同牌重复购买、不买离开、刷新；狗/乞丐移动、金额和反应顺序仍有未知 | 以连续录像补关键规则再替换 TEST；分别验停留/经过、同格设施、免疫/转移、破产生成、交易中保存和中断。展示 NPC 身份与预计后果，保留底层道路和产权，不把 NPC 画成另一种固定商店 |
| P1 | 骑士庄园机制与地图信息 | 两个黄色图标仍是 `unresolved`；街道分组、设施释放细则、多入口原作语义和部分地价待核。拓扑完整不等于地图机制完整 | 给未识别节点明确提示；取得原作机制证据后逐项接入。维持 102 节点/104 边和全部地产；任意入口引用同一产权且一次落点不重复收费，释放位置/朝向可复查，正常缩放可辨道路、产权、等级、NPC和目标入口 |
| P2 | 更完整的原作内容 | 新闻全表、其他地图机关、热斗、挑战领主及对应 AI 尚未完整实现 | 每项独立建立证据、数据和完整对局验收；不以当前自由比赛闭环替代全目标，也不把未核黑衣商人加入已还原清单 |

建议下一次先交付“逐卡报价候选表＋热座停顿点记录”，再确定代码改动范围。现有四种小游戏和 NPC 已可玩，优先纠正规则与体验，不重复建设同类系统。3D、联机和原创地铁/红绿灯扩展另列后续设计，当前继续沿用单机 2D 与原创占位素材；原作研究截图不能作为发布美术。

## 证据与未知项入口

## 下一次实施的交付要求

每项写明具体问题、拟改规则、证据等级、影响范围和验收场景。价格策略改变要明确适用新局还是旧局，不能静默重算旧存档资金、产权或未结账单；真实历史 fixture 与两组 RNG 的续演继续保留。模型回归、实际界面操作、自然整局分别记证据，不互相替代。

完成一组后更新分类策划，列出仍未还原的内容，并发布可试玩 Git 检查点。此前飞书版本保留历史语义，本稿作为新一轮页面发布来源，不用新结论静默覆盖旧页。
