# 第十六轮：开局资源、日历与分类物价规则

2026-11-08。本文描述v0.16可执行规则，原作证据见 `docs/research/r16-settings-followup.md` 与 `docs/research/r16-price-scope.md`。完整玩法还原仍未完成；不是把本版测试常数认定为原作数值。

## 比赛设置

现金、存款分别配置，并对全部席位一视同仁。界面预设各100000、物价周期15天，来自实机首次进入设置菜单时的值；是否出厂默认未知。两项上限各500000已在连续拖动滑块中确认；本版最小0、步长1属于测试范围。可选择物价关闭或1/5/10/15/20天；原作间隔最小1已确认，关闭和其余列表不是原作全部选项的复刻。

原作明确有有限期、无限期。本版有限选项10/20/30天为测试时长；无限期不按日数结算，直到只剩一个有效阵营（或使用GM结算）。无限期仍推进物价、股票、乐透、神仙及其他周期。有限期到期按既有团队净资产规则结算，具体原作终局排序仍需核验。

## 日期与涨价

从第1天、物价1开始，全部席位轮转一遍后进入次日。银行操作、用卡、反应卡、新闻、小游戏内部参与者都不增加天数。已证四席正常轮转的日界；破产、住院等特殊跳过路径沿本项目席位循环作为测试扩展。

采用公式 `1 + floor((day - 1) / interval)`，周期0时物价恒为1。间隔1的首次日界1→2有连续实机证据；一般间隔公式为样本推导。有限期的内部终局哨兵轮不会增加物价，结算使用最后可行动日的指数。无限期没有此封顶。

## 收支类别

| 类别 | 本版行为 | 证据或边界 |
| --- | --- | --- |
| 地产租金 | 建筑、街区、队伍、神仙、角色修正后乘物价，再取整数；账单进入反应链前确定金额 | 原作教程确认租金受物价影响；基础租金、修正次序和取整仍测试 |
| 房屋补贴新闻 | 5000×本次冻结物价，只付当前席 | 5000@物价1、10000@物价2的直接样本；更高值为推广 |
| 小游戏操作席 | 显示分数×本次冻结物价 | 物价2和6的连续余额支持；拆炸弹采用相同换算仍为推广 |
| 小游戏其他席 | floor(显示分数×物价÷3) | 物价2时两场实机均为显示分数×2/3；推广到其他物价/模式是测试推断，不能误写成再乘2/3 |
| 购地、加盖、重建、研究、购卡 | 继续独立测试报价 | 缺原作逐项公式，不从租金倍率推导成本倍率 |
| 乐透、现金格、其他新闻、热斗伤害 | 既有测试规则，本轮没有统一乘价 | 某些类别有物价相关证据，但作用时点及精确公式不足；继续待还原 |
| 存取款、余额转移、百分比利息、股票 | 保持各自公式与资金守恒 | 不对已有余额或已结算金额再乘物价；现行月结20天/2%仍为测试配置 |

静态地图价格与面额不改写。界面购地/升级价格与实际扣款继续共用报价函数，租金预览和实际基础账单共用建筑规则。商业中心转盘另有既有随机倍率；报价不意味着所有随机倍率已经确定。

## 服务报价与一次结算

进入新闻或任一小游戏时，在外层服务记录中冻结日数、物价和其他席除数。小游戏内部v1历史继续保存基础分及基础reward，外层现金换算返回实际金额；界面结果表与侧栏均显示实际待领现金。它们不是两次奖励。领奖清除服务，重复确认无效；GM中断丢弃未领取服务，不泄漏现金。

服务阶段不能结束棋盘回合，因此正常流程无跨日新闻或小游戏。v7存档严格要求报价与本日策略一致，缺字段、错误类型和篡改物价均拒绝；读档不会重抽或重算计分轨迹。

## 存档兼容

v7新增 `economy_config`，包含初始现金、初始存款、物价间隔和策略标识。新界面采用 `r16_samples`。历史v1—v6恢复为 `legacy_v6`：10000/0是原始开局元数据，不覆盖角色当前资金；物价固定1、小游戏所有席仍1:1，新闻仍5000。旧局中尚未领奖的分数不会被改成新策略。读取旧局后按同设置重开仍沿旧策略，主动应用新局经济设置才切换。

真实旧存档 `tests/fixtures/round15-v6-economy.rms` 在改动前由原版序列化器冻结。兼容验收逐字段保护资金、地产、服务进度、元数据和两个随机状态，不以新格式伪装旧档。更早v4/v5真实性样本仍保留，测试仅允许新增中性经济字段。
