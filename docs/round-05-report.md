# 第五轮：载具、路线、移动状态与爆炸连锁

日期：2026-11-08。目标仍为 Steam PC 国际版《大富翁11》完整玩法重建；当前为 v0.5 集成验证版，**未完成原版还原**。本轮用新资料修正了已知操作差异，并把更多卡牌接入同一局中的移动和反应流程。

## 本轮对照与实现

| 项目 | 当前可执行行为 | 原版对齐情况与未知 |
|---|---|---|
| 普通岔路 | 途经随机转向；恰好停在岔路后起步可选方向；查询不会重抽随机结果 | 同期评测确认该区别；掉头选项、概率和机关例外仍待核验 |
| 载具 | 步行/机车/汽车上限1/2/3骰，可选骰数，显示各骰点数；爆炸毁车独立于住院防御 | 减骰有来源；每回合默认骰数和完整覆盖优先级暂定 |
| 遥控/超级骰 | 选择目的地及整条合法路径，银行暂停后继续；超级骰可选后退1～6步 | 遥控选落点有来源；多骰范围及多路线呈现细节仍待实机对照 |
| 梦游 | 仍掷骰、逐格移动；界面自动推进；禁主动用卡、弃牌、交易、银行和购建；不收租，作为访客仍付租 | 不能取存款/不能收租有11代资料；自动GO和部分经济限制来自通用说明或实现选择 |
| 乌龟/停留/转向 | 乌龟3次行动每次1步，遥控可突破当次步数；停留原地一次；转向修改后续朝向并清除冲突路线 | 天数扣减、停留不重触发落点等为明确测试规则 |
| 路面物件 | 香蕉加一步；果冻改为反向两步；陷阱停止并影响下一次行动；机器人可选择前方10步清除路径 | 滑动剩余步数、陷阱持续时间和清除集合未完全核验 |
| 传送 | 选择角色和目的道路，不当场触发服务或扣附身炸弹步数，继续原行动 | 触发时点/范围仍未知，该行为是当前测试选择 |
| 爆炸连锁 | 地雷、飞弹、量子、急速弹可引爆范围地雷/炸药；物件去重；建筑多入口在每个爆点内只计一次 | 图距离半径1为测试参数，绝非已恢复的11代空间半径 |
| 附身炸弹 | 经过附身、30实际步计时、追上传递、归零爆炸；界面显示余步 | 附身当步/传递顺序/瞬移等计步边界均明示为测试选择 |
| 爆炸反应 | 多个爆点逐项处理个人防御，车辆和建筑损害不撤销；完毕后续接路面物件、银行及落点 | 多次命中保留最长住院、同格急速弹合并等仍待核验 |
| 研究所 | 五级池接入传送门、陷阱、超级骰、传送、量子飞弹 | 研究时间、费用及获取组合未完全恢复，合成系统仍缺 |
| GM | 新增载具设置、剩1步附身炸弹、清弹、手动路口开关；工具面板可滚动 | 仅测试工具，不计入原版功能完成度 |

## 卡池进度

## 交叉审查修复

1. 附身炸弹恰好归零时，防御后必须继续处理脚下物件；拆分抵达阶段，避免遗漏或重复扣步。已携弹角色碰到另一个定时炸弹不会被误当地雷引爆。
2. 转向、果冻、换车、传送与旧遥控路径冲突时清理控制状态；梦游中住院记住受击位置，醒来不会倒回施卡地点。
3. 梦游地主不收租；梦游访客仍支付当前测试租金。银行服务不会因相邻入口或爆炸续接而重复打开。
4. 量子夷平后的有主空地不收费，也不能直接升级或用机器工人生成“空地楼层”；先改建选类型，再升级。原作重建费用/权限仍待核验。

## 验证

路径规划、移动、爆炸、第五轮交叉审查均0失败。既有建筑、卡牌、攻防、股票与清偿回归亦通过；核心固定种子50场完整对局0失败。旧清偿测试原先用“空地类型+楼层”构造租金，本轮改为实际住宅，保留原金额守恒和清偿断言。

实际界面输入完成汽车/三骰/目标路线、传送选择、自动梦游、GM载具/炸弹设置以及无懈后续接，`R5_UI failures=0`。这些专项场景明确使用测试数据和GM构造，不冒充自然对局。另有无GM完整20轮界面对局：`FULL_UI_MATCH actions=1317 rounds=21 failures=0`，actions包含等待动画，21是20轮完成后的计数。

证据在 `testing/round5/`。资料及明确排除的4Fun/10代参数见 `research/r11-movement-explosions.md`；实现边界见 `round-05-movement.md` 与 `round-05-explosives.md`。
