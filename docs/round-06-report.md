# 第六轮验收：神仙、角色与剩余主动卡

2026-11-08，v0.6。目标仍是Steam PC国际版《大富翁11》的玩法重建。本轮没有完成全游戏还原，没有增加联机或正式美术。

## 当前新增

- 16位原作角色规则可选，另有原创无天赋；四席仍为同机热座，四种原创几何外观与规则分开选择。默认启用天赋和道路神仙，也可在选人页关闭。
- 十种神仙生成、道路相遇、附身替换、到期、入场现金/卡牌、租金修正、经过建筑与停留升级等接入。神仙与定时炸弹共享附身槽；莎拉免疫仍清旧槽。
- 八张主动卡接入：购地、换屋、怪兽、请神、送神、魔术、绿化、神眷。目录48项中47项有可执行效果，免费卡未接；这不是47张全部交互已还原的声明。
- 五类五合一自动合成；研究等级顺序修正为传送门、超级骰、陷阱、传送、量子飞弹。
- 神眷提供带神仙名称的目标选择；换屋分别选择当前临街房屋和范围内己方至少1级房屋/连锁店。角色/神仙图鉴展示能力和缺口。F1支持附身、清除和道路神仙放置。

## 独立审查修复

魔术按实际分发数量计数，避免发牌过程中自动合成缩减手牌导致一方多拿。衰神只有实际失去卡牌时触发意外失牌天赋。换屋校验当前位置、建筑类型、己方目标等级；非法操作保留卡牌。图鉴兼容角色资料字符串型待核验字段，避免打开时报错。

## 验证

Godot 4.6.2 命令行执行15项逻辑测试全部0失败，包括50局核心模拟、道路建筑合同、建筑经济、卡牌、股票、防御、路线、移动、爆炸和新角色/神仙/审查回归。新增界面测试通过真实鼠标事件验证选人、附身、神眷、自动合成、绿化、换屋、图鉴和GM结算，0失败。

默认开启天赋和神仙的20轮完整UI对局自然结束，actions=1471，rounds=21（最后一轮完成后递增），failures=0，没有使用GM。截图和日志在 docs/testing/round6。该用例证明闭环，不覆盖每张卡的所有组合。

## 已知边界与下一轮重点

神仙基础时长、现金额、概率、范围和到期重新落图规则未全部核实；当前到期退场，不重新生成。角色返牌概率、糖糖折扣仍为测试值。NPC、热斗伤害、团队依赖与免费卡天赋不能宣称已完成。神眷暂只邀请地面神仙；第六绿化配方已有社区线索但尚未实现。地图还是117道路/24地块的集成布局，不是原作地图。

下一轮优先补免费卡与金损反应链、神仙剩余交互和合成边界，再推进原版地图拓扑/出口/机关、NPC、单机AI和存档。热斗、团队、挑战及全地图依然是后续还原范围。先核实规则，再用可重复对局验证；未知数值继续集中标记。
