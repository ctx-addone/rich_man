# 建筑与经济策划

## 经济参数

| 项目 | 第一版数值 |
|---|---:|
| 每人初始现金 | 10000 |
| 进入起点收入 | 1000 |
| 地铁票价 | 200 |
| 地产购买价格 | 1000 / 1200 / 1400，按地图规则循环分配 |
| 地产基础租金 | 180 / 220 / 260，与对应价格档配套 |
| 升级费用 | 每级 600 |
| 最大建筑等级 | 3 |
| 默认比赛轮数 | 20 |

## 购买与建设

最终落点为无主地产时，可按标价购买，也可跳过。购买要求现金足够，成功后归当前角色所有并设为 1 级；买地操作不能靠自动变现其他地产强行完成。

最终落点为自己的地产时，可支付 600 升级一级，或跳过。最高 3 级；达到上限或现金不足时不允许重复扣款。第一版只设一种可升级地产，不加入银行、医院、旅馆等可自定义经营的大型建筑，也不加入地产交易、拍卖或抵押的独立界面。

## 租金

最终停在其他未破产角色持有的地产时支付租金。

`租金 = 基础租金 × 等级²`

| 价格档 | 1级租金 | 2级租金 | 3级租金 |
|---|---:|---:|---:|
| 1000 | 180 | 720 | 1620 |
| 1200 | 220 | 880 | 1980 |
| 1400 | 260 | 1040 | 2340 |

已激活的免租效果抵消下一次实际租金支付，并在抵消后消失。它不抵消公共事件支出、地铁票价或主动购买的费用。

## 清偿与破产

租金或强制事件支出超过现金时，按实现的稳定顺序自动出售地产，每处回收其账面资产原值的 50%。账面原值包含购买价格和已投入的升级费用；被卖出的地块重新成为无主地块，并清除等级。现金足够清偿后停止出售。

若全部可出售资产仍无法清偿，玩家破产，退出后续回合。不能继续操作卡牌、购买地产或参与排名获胜。此版本用自动清偿压缩流程，不加入债务谈判与手动抵押管理。

## 资产与胜负

`地产账面价值 = 购买价格 + 600 × (等级 - 1)`

`净资产 = 当前现金 + 所持地产账面价值总和`

注意账面净资产与强制出售所得不同；结算按全额账面价值计入，强制出售只能收回一半。

20 轮结束后比较未破产角色净资产，最高者获胜，净资产相同则并列获胜。若此前只剩一名未破产角色，则立即结算，无需等满 20 轮。GM 结束比赛同样使用正常净资产排名，不能伪造额外胜负条件。

## 数值调试重点

观察单局耗时、领先者滚雪球速度、三级租金能否造成实际威胁，以及地铁是否让地产完全失去价值。第一轮测试优先确保闭环和账务正确；上述价格不是对任何原作数值表的复制，也不是最终平衡承诺。
