# 基础美术素材清单与占位规范

## 本版素材策略

优先用简洁色块、线条、文字和不同色彩的角色标记，让规则可读。已在确认的 `dynamic08triumph@gmail.com` 账号创建 [Figma 素材草稿](https://www.figma.com/design/DczcPjRbOMMmaFGoUEI2QX?node-id=3-2)，未使用或修改 `Houkai.dynamic` 账号。未找到可访问的 Warland 参考源，因此本版为原创几何占位素材，不声称复用了或参考到该项目的具体设计。

共 15 个 SVG：4 个角色、0～3 级的 4 个建筑状态、7 个图标。本地清单为 `assets/manifest.json`；角色、建筑、地铁、起点与事件图形已接入游戏，信号灯仍使用程序绘制的方向十字以保证可读性。这些素材只用于原型，不等于正式角色立绘或最终概念设计。

## 素材分类

| 分类 | 本版需要 | 占位表现 | 未来替换要求 |
|---|---|---|---|
| 角色 | 四种视觉身份 | 不同颜色、编号和简洁头像/棋子 | 四张独立立绘及四套棋子，均无角色技能 |
| 道路 | 直线、转弯、分岔和十字路口 | 线段与格子连接 | 保持相同节点及出口信息 |
| 地产 | 未购买、已购买、各等级 | 地块色带、持有人号、等级文字 | 建筑外观能区分等级，保留持有人标识 |
| 起点 | 一处 | 特殊底色与文字 | 能迅速辨识收入触发点 |
| 地铁站 | 三处 | 统一图标/文字与站点编号 | 地铁目的地应与地图站名一致 |
| 信号灯 | 两组 | 方向文字和红绿状态 | 即使不辨色也能理解通行方向 |
| 公共地块 | 事件及规则所需地块 | 不同符号与名称 | 不遮挡角色、产权和路线 |
| 卡牌 | 少量功能卡 | 卡名、效果文字、数量 | 图标不能代替效果说明 |
| UI | 菜单、按钮、面板、排名、GM | 统一字体与简明色块 | 保持操作阶段、危险操作和禁用态清楚 |

## 阅读优先级

最高：当前角色和可用操作。其次：路线、格子类型、地产持有人、租金与等级。再次：日志、辅助说明和装饰。角色停在地块上时，不能完全挡住关键地块信息。

## 交付与来源

本版几何 SVG 由项目原创生成，没有外部商业图像依赖，文件清单见 `assets/manifest.json`。若之后引入第三方 SVG/PNG、字体或音效，需补充来源、许可证、作者和用途记录。未来正式 3D 资源独立排期，本版不以仿 3D 贴图增加工作量。
