# 第八轮：单机电脑与自动托管

本轮新增可执行的单机电脑决策器，使用同一套游戏命令与状态机。同期PC评测明确原作具有自动选项，未提供旧代多档AI强度：[游民评测](https://www.gamersky.com/review/202210/1528427.shtml)。本项目使用原创确定性启发式，不宣称复刻闭源算法、原作水平或挑战领主强度。

## 接口与持久状态

`AI.step(game) -> bool` 每次执行一个有效命令。UI按当前阶段决定操作席位：reaction用reaction_player，否则用current；只有该席位是电脑或托管才调用。返回false表示终局或无法推进，UI必须停止并显示原因，不无限重试。没有私有记忆、计时器或私有随机数；保存模型状态即可恢复相同AI决策。card_used、商店限购、余额、建筑等级和研究进度提供终止边界。

决策不读取随机数未来序列，不通过GM修改局势。选择公开可见的目标和合法路线。游戏命令本身照常使用游戏随机数，例如普通岔路由移动模块决定；AI不复制RNG抽取未来结果。

## 当前策略

- 掷骰前最多主动使用1张卡；优先载具、清自身坏神/炸弹、邀请好神、升级/购地、收益和攻击卡，随后选择载具允许的骰数。不能用的牌跳过，不阻塞行动。
- 遥控与超级骰选择已有合法路径，比较落点可购/己方地产、租金和酒店风险，并避免已知道路物件；机器娃娃优先清有物件的路径。
- 岔路在规则允许选择时比较公开道路收益，不更改普通随机穿越规则。
- 银行保留最多3000现金，其余存入；不足时从存款补至储备。这个策略阈值是AI设计，不是原版资金规则。
- 商店优先免费、遥控、工人、无懈等可用卡，每类不超过2张，保留现金储备并遵循商店限购/手牌容量。
- 落地购买住宅；大型地产优先酒店、商城、研究所、地产公司。保留最低资金后升级；可启动并领取研究。
- 防御优先免费或无懈，然后转移给合法目标中资产较高者，之后同命；无可用防御则承受。没有绕过状态限制或提前看对手未来骰点。

## 验证与边界

ai_test验证8局50轮（4种子×天赋/神仙开关），全部自然完成，有实际用卡、产权购入与银行存款；另有购物、研究启动/领取、免费与无懈防御、无可用主动卡继续掷骰的针对用例，以及同种子双实例决策轨迹一致性。所有对局不调用GM。

当前策略不主动使用全部48张卡，也不主动做股票投机、复杂交换建筑或团队协商；无法收益性判断的牌保留。这是基础单机自由比赛AI，不代表挑战/PVE、团队策略和全部原作决策已完成。原作全部模式、领主与难度仍在完整目标内。
