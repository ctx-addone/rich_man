# 第十轮验证证据

Godot 4.6.2 stable，Windows。逻辑测试用headless命令行；界面测试用Compatibility渲染、1440×900视口与真实鼠标事件。

- `model-results.json`和28份同名log：模型套件退出码、脚本错误扫描与断言结果。
- `teams_test.log`：身份、无效配置、地产协作、资产/生存/并列胜负、4场自然比赛。
- `team_ai_test.log`：4种子×2v2/FFA共8场，敌我行动与防御、队友支援及随机轨迹一致。
- `team_interactions_test.log`：共享建筑效果、卡牌集合与友伤；不使用全面友伤免疫代替逐卡规则。
- `round10_save_test.log`：真实v1/v2迁移、v3续演与22项拒绝；旧存档专项继续保留并通过。
- `team-ui.log`及01—05截图：组队入口、非法单队阻止、友方酒店、协助升级、保存/重开/结果、自然全电脑比赛。
- `full-team-ui.log`及07截图：无GM热座2对2，20轮上限自然完成，1413动作，rounds=21，0失败。
- `services-ui.log`、`handoff-ui.log`：特殊设施和人机防御交接回归；截图在对应子目录。

专项UI用局势构造验证指定边界，最后的全电脑组队与完整热座测试不用GM结算。已目视检查新队伍选择、友方建筑操作与团队/个人结果对照。未运行原版游戏，因此这些测试不等于原版数值和全部组合的实机证明。
