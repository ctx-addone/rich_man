# GM 工具与验收计划

## GM 目的

GM 供本地测试使用，用于快速构造局面，不参与公平对战承诺。显示当前阶段、角色、节点和日志；使用修改状态的操作后应立即刷新棋盘和侧栏。GM 不应让已结束的对局恢复成可继续的半结束状态。

## 最小命令集

| 能力 | 用途 | 检查 |
|---|---|---|
| 指定下一次骰子 | 检查准确落点和路口 | 只影响规定的一次骰子 |
| 给角色加减资金 | 构造买地/升级/资金不足 | 金额与日志、资产统计一致 |
| 传送到节点 | 快速测试地产、地铁、起点 | 节点必须有效，不保留过期移动选择 |
| 发放卡牌 | 检查四种效果 | 不绕过正常使用时机规则 |
| 结束比赛 | 检查结果排名 | 使用正常净资产计算 |

对局中按 F1 或点击“GM · F1”打开弹窗。可指定下次骰子为 1～6、选择角色加减现金、发牌、传送、强制结算。GM 传送当前角色会终止剩余移动并立即触发落点处理；传送非当前角色只改变其位置。传送起点不发放 1000 经过收入。GM 减钱最低减到 0，不直接触发破产；应通过实际租金或事件支出验证破产。使用 GM 的比赛会显示测试局标识。

## 人工验收路径

1. 从主菜单进入，看到一张地图、四个不同角色并开始比赛。
2. 连续操作四个席位，检查交接与轮次增长；确认所有角色都由人控制。
3. 掷骰后不可重复掷骰；路口选择只允许有效道路。
4. 用 GM 构造无主地产落点，分别购买与跳过；资金及产权正确。
5. 自有地产逐次升至 3 级；超过上限和钱不足都不能扣款。
6. 另一角色停在该地产，核对租金为基础租金乘等级平方。
7. 激活免租卡后缴租，检查只免一次；公共事件支出仍生效。
8. 使用定步卡，骰子为 6；同回合第二张卡被拒绝。
9. 使用交通卡，合法路口方向改变；没有出口时仍能结束回合。
10. 最终停在每个地铁站，检查两个目的地、200 票价及换乘结束。
11. 强制支出超过现金时检查自动变现；无法偿还时破产并跳过席位。
12. 仅余一人时立即结算；正常跑满 20 轮也能结算，净资产并列显示并列获胜。
13. GM 结束对局后无正常行动；重开后资金、地产、卡牌、日志全部重新初始化。

## 已知范围限制

没有联网、AI、持久化存档和独立 PVE 战役。占位美术不作为最终视觉品质验收对象。单局 20～30 分钟只是体验目标，需真人完整对局计时后再确认。
