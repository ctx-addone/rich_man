# 第9轮：乐透与魔法屋服务

这轮在集成测试地图加入两种《大富翁11》传统模式服务，补齐行进暂停、选择、结算及继续回合。它是已找到证据的规则子集，不是原作地图或完整特殊设施目录。研究来源、证据等级及未确认项见 同目录《特殊服务原作规则补证》（本地文件 `docs/research/r11-special-services.md`）。

## 布局与启用

`setup(..., {"specials_enabled":true})` 开启；旧三参数调用默认关闭，以保持旧测试和存档的地图语义。117 个道路节点的坐标和连接保持原样，仅测试地图的节点 17 改为 `lottery`、节点 51 改为 `magic`。节点编号与布局不声称来自原作。关闭时它们仍是旧机会事件格。

## 乐透

经过即进入 `lottery` 阶段，包括恰好用完最后一步。玩家选号购票或离开；离开后保留剩余步数、已指定的路线与行进方向。每段投骰行程对同一服务格去重，避免经过与最终落地重复购买。GM 传送视为重新访问。

同期 PC 评测支持经过购买及开奖前持有多个号码；社区 11 代资料给出票价 5,000、10 代以后每隔 15 天开奖。其物价倍率尚未核定。本轮不套用旧作的 1,000 票价或每月15日规则。

下表集中记录当前 `Specials.TEST_PROFILE` 中的工程配置，不应当作已核定原版数值：

| 配置 | 当前值和行为 |
| --- | --- |
| 号码范围 | 1～10，均匀随机开奖 |
| 每注价格 | 5,000；有11社区证据，暂不乘物价 |
| 每次到访限购 | 3 注，可重复购买同号，也允许多人持同号 |
| 初始奖池 | 10,000，每注全部加入奖池 |
| 开奖周期 | 每完成15个全局轮次；首次在第16轮开始边界 |
| 无人中奖 | 奖池滚存；本期所有票清除 |
| 多人/多注中奖 | 按有效中奖注数均分；整数余数依购票顺序分配 |
| 破产 | 破产玩家的票不领奖；既有票款不退款，票在下次开奖统一清除 |
| 中奖后 | 自动发至现金，奖池归零；不自动补充初始奖池 |
| 局末 | 若刚完成的最后一天恰逢开奖，先开奖再排名；不足一个周期结束不额外开奖或退票 |

购票只使用现金，现金不足时整笔拒绝，不变动票据、奖池、次数和随机状态。`draw_round` 在结算时推进，阻止同一边界重复抽号或领奖。当前服务不接入尚未实现的圆圆购彩附加损失，也不假设主动购票可以用免罪卡取消票款。

## 魔法屋

只有最终停留触发 `magic` 阶段。玩家先提交效果，之后才抽取条件；打开菜单和无效选择不消耗随机数。当前提供：

- 摧毁建筑：原作存在该效果；本轮测试解释为符合条件者名下所有已建地产降1级，包括商业地产。归零变为空地，保留所有权并清空研究。原作作用范围及层数仍未核实。
- 获得3张卡：给符合条件者各发3次随机卡，复用当前卡池、8张手牌上限与自动合成。卡池权重和溢出处理仍为测试策略。
- 存入所有现金：现金全部转为该角色存款，资产总量不变。

三个效果有11代社区证据，得3卡另有同期实玩攻略佐证。条件子集为驾驶汽车、总资产最多、地产最多；均匀选择条件、最多者并列全选、无匹配对象不重抽均为测试策略。总资产复用现有现金、存款、股票市值和地产价值。条件在选择后抽取，未提供玩家预览或操纵随机条件的正常操作。

破产、住院、入狱、度假的角色不参与被作用对象；梦游角色仍在地图上，可成为效果对象。主动进入服务要求当前角色状态正常，梦游/冬眠不能操作；凶神跳过这两类设施是待核实资格的集成规则。自身也可能被条件选中。未加入热斗专属替换效果、失去半数手牌或入狱效果，避免在取整、防御和计时未知时泛化伤害规则。

## 与现有事件衔接

道路爆炸及防御先于乐透入口；成功免疫后接着访问乐透，住院则结束行动。魔法屋与地产 frontage 共用测试道路时，先处理租金及防御，完成待处理落地队列后才打开魔法屋。服务本身不能绕过尚在等待选择的被动防御。

商店首次到访使用 `Shop.enter` 固定一份随机货单，查询不刷新；买入成功移除该项库存。其状态由 `shop_stock` 和 `shop_visit_serial` 记录。神仙全局轮循环由 `Gods.advance_round` 接入，只受 `gods_enabled` 控制；不在局末的未游玩一天补神。详见 同目录《神仙循环与随机商店》（本地文件 `docs/round-09-world.md`）。

## 状态与接口

`specials_enabled`、`lottery_state`、`service_visited`、`pending_service`、`magic_last_result` 属于公开模型状态，UI/AI/存档使用同一接口。

```text
lottery_state = {pot, tickets:[{player,number}], draw_round,
                 last_draw:{round,number,pot,payouts}, last_winners, draw_count}
pending_service = {kind,road,purchases} 或 {}
magic_last_result = {effect,condition,targets} 或 {}
lottery_numbers(); buy_ticket(number); close_lottery()
magic_options(); choose_magic(effect_id); close_magic()
```

`close_magic` 是测试交互中的放弃选项；原作是否允许直接放弃仍待核实。提交效果立即清除待服务状态，防止重复执行。新回合和结束游戏均清理待服务状态。

## 验证

`tests/services_test.gd` 覆盖117道路几何、旧选项兼容、选号及现金原子性、限购、路线保留、重复访问、最终一步、睡眠/凶神、爆炸防御续行、分奖余数/破产/滚存/重复开奖、局末开奖、魔法随机顺序/空目标/并列/缺席角色/手牌上限/租金防御续行，以及三场35轮完整游戏。另运行旧核心、资金、防御和神仙回归测试。

目前仍缺：原版完整设施目录、票号和奖池公式、物价及购彩天赋、完整魔法效果与条件表、针对领主/团队/热斗模式的准确资格矩阵。不会用本轮测试参数填成已完成还原。
