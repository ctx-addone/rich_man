# 第八轮验收：单机托管与存读档

2026-11-08，v0.8。继续Steam PC国际版《大富翁11》的2D玩法重建。本轮从自由对局的热座闭环推进到可与电脑对战、可保存继续的本地版本；完整原作模式、地图与全部规则仍未完成。

## 单机控制

默认一名真人与三名电脑，选人页可逐席选择；局内托管窗口可改变控制，电脑行动可暂停或直接接管。防御阶段依据被攻击者的席位决定真人或电脑应对，不把当前行动者当成防御者。电脑攻击真人时等待真人确认，电脑防御完成后交回原行动者。弹窗期间暂停自动操作，读档后电脑也先暂停。

AI使用正常命令完成主动用卡、合法路线、银行资金、商店购买、地产购建、研究、防御与回合结束。没有通过GM获胜，也不读取未来骰点或股票随机结果。算法为原创基础启发式，尚不主动使用全部卡牌、不做股票投机或团队决策；不声称达到原作AI水平或挑战领主行为。

## 保存与继续

同期PC资料支持每次保存新增记录、读取历史列表，本轮因此实现动态存档列表而非固定槽位。主菜单和局内均可读取；每份有自定义名称与时间。保存精确记录玩家、产权、随机状态、股市、控制路线、银行经过、未结算攻击/金损、落地队列、附身、炸弹和特殊停留。

存档采用版本化普通数据二进制，保留64位随机数和整数道路key。校验魔数、长度、摘要、模型结构及引用，禁止对象加载；全部校验后创建新Game。错误或损坏文件不替换当前局。UI保存控制席位、外观和GM标记；读取后重新要求交接确认，清选择高亮并暂停电脑。

本项目允许稳定命令边界上的移动、银行、反应等阶段保存，也允许同机热座保存；原作PC具体阶段限制尚未核实，热座保存属于本项目便利行为，不冒充原作多人存档规则。当前schema只承诺本版本布局，未来地图或状态变化须迁移或升版本。临时文件校验与备份替换不是断电事务保证。

## 审查修复

独立审查修复了可选方向/辉煌/岔路字段类型、无状态却处于拘留阶段、负附身时长等非法存档；恢复输入先深拷贝，两个恢复实例不再共享玩家和市场数据。UI另外校验席位/外观metadata，错误类型保持现局。电脑席位的股票与研究不能由旁观者绕过接管直接操作。

## 验证证据

- AI：4种子×天赋/神仙开关，共8局、每局轮数上限50，全部无GM自然结束；专项覆盖购卡、研究、银行和防御，并验证双实例决策一致。
- 保存：一局10轮在每条命令后序列化重建，230步自然结束；骰子与股市独立随机状态续演一致。
- 复杂保存：遥控途中银行暂停后继续指定路径；飞弹连地雷/炸药的多玩家多次防御；医院滞留返回；梦游移动计时；酒店待付款恢复后免费与住宿。均验证同动作续演结果一致。
- 界面：第4轮股票/攻防、第7轮金损、第8轮保存/控制、第8轮人机交接四套真实鼠标测试均0失败。新增UI包含全电脑10轮上限自然结算、移动保存/主菜单读取、历史新增、损坏文件及错误metadata拒绝、电脑/真人双向防御与接管。
- 原有全人类热座20轮UI仍自然结算，actions=1399，rounds=21，failures=0，无GM。

本轮运行AI、保存、独立存档审查三套逻辑测试，均0失败；既有18套模型测试的上一轮证据保留。本轮未改既有游戏规则核心，未将未重跑的历史套件计作本轮新验证。证据位于 docs/testing/round8。
