# 第4轮攻击与反应

新增无懈、转移、同命、冬眠、飞弹，共22张活动牌；48项资料目录保持完整。这里的 implemented_provisional 仅表示可运行并有测试，不代表原版复刻完成。

攻击先验证目标，成功后消耗主动牌，进入 pending_attack。current 始终是原行动者，reaction_player() 是当前真正受击席位。reaction_options() 提供持有且可用的反应卡；resolve_reaction("", -1) 表示承受。转移必须传 reaction_targets("transfer") 内的目标。不合法的反应不耗牌、不改变状态。没有可用防御牌时自动结算。

无懈免一次入狱/住院；转移将个人效果转给其他存活且无状态角色；同命用于谋划和冬眠，让自己和施卡者同时承受。冬眠不允许无懈/转移，已睡眠角色不能防御。施卡者自己被命中时结束其行动，其他情况恢复原 phase。地雷个人免疫不回滚建筑损害，成功免疫后继续剩余移动、经过服务及最终落点。

明确 provisional 的选择：攻击图距离6；爆炸角色范围仅同道路节点，地产仅临街地块；转移不限距离但每次攻击每席最多处理一次，避免循环；同命不递归反击；2天暂按未来2次个人行动计，状态结束复用旧 return_pos/return_previous；梦游未激活，不能拿跳过回合替代梦游。设施/冬眠状态覆盖边界仍需原版验证。飞弹1次行动住院、建筑降1层，地雷2次；建筑损害独立于个人防御。

未实现连爆、爆炸半径扩散、金钱伤害与阈值防御、热斗、车辆损毁、神仙减免。免费卡维持未实现，不臆造阈值。非原作特定模式或地图。依据见 docs/research/r11-cards-characters.md；本轮没有原版实机验证。
