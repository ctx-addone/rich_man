# 第十五轮：打气球小游戏

打气球已成为骑士庄园可抽中的第四种小游戏。当前角色点击四列底部炮钮，结算所选纵区的全部可见气球；炸弹比奖励气球升得快，可以等待其飞出屏幕后再开火。当前玩家结束后，其他席独立自动完成小游戏，结果面板统一确认后各自领取一次现金，再回到棋盘回合。

## 原作证据与测试参数

[KillKill龍原作实机约45:18说明页](https://www.bilibili.com/video/BV1hw4m1C7Tm/?t=2718)直接写明点击按钮、取得对应区域全部物品、命中炸弹结束、炸弹飞得快可先等待。本片段来自骑士庄园，同局已出现投娃娃、接金币和拆炸弹。原作标题为“打气球”，此前评测中的“射气球”是俗称。完整取证见 `docs/research/r15-minigames.md`。

下列交互有原作证据：四纵区、四个射击按钮、同列可有多枚气球、一次击中整列、金币/元宝/炸弹三种携带物、炸弹更快且可以等它飞走、命中炸弹结束。

本实现把其余未核项集中放入 `scripts/model/shoot_balloons_rules.gd` 的 `TEST_PROFILE`：

| 参数 | 当前值 | 证据边界 |
|---|---:|---|
| tick_seconds / ticks | 0.5秒 / 40拍 | 20秒测试时长，不声称原作精确时长 |
| top_height | 8 | 整数高度0–7可见，达到8移除，为本版离散轨迹 |
| reward_speed / bomb_speed | 1 / 2 | 更快这一关系已证，具体速度与倍率未核 |
| coin_value / ingot_value | 100 / 500 | 测试分值，不能因接金币使用同值就称此游戏已证 |
| 新生 | 每个非结束拍一枚，4列与3种携带物分别等概率 | 生成密度和概率均为测试 |

**含弹列优先终止，当次列内奖励不计、先前已得分保留，均为明确测试规则。** 实机说明只确认命中炸弹结束，尚未确认同列奖励优先级和既得分是否保留。原作样本当前角色19800分、物价6获118800现金；本项目当前按基准物价1，奖励等于各席分数，未加入全局物价机制。

其他参与席沿当前原型约定取所有未破产席；状态异常席的参与资格、自动成绩分布仍是测试策略。原作热座视频支持“触发者手操、其他本地人类也自动出分”，所以不会让其他人再依次手操一轮，也不把当前玩家的成绩复制给他们。

## 操作与计时顺序

`shoot(game, lane)`只接受0–3，锁定本拍的一次输入；连续点击不会重复开火、修改已锁定列或提前抽取新气球。`tick()`依次执行：

1. 结算点击时已可见的整列；包含炸弹则按测试规则终止。
2. 其他列气球向上移动，越过顶部的气球移除。
3. 若达到时限则结束；否则用对局RNG生成一枚新气球。

新生成的气球不会在同一拍被此前的射击命中。命中炸弹或到期的结束拍不会额外生成物品，也不消耗下一拍的随机数。模型不读取墙钟；界面计时器负责调用，暂停时不调用tick，存档保持拍数和已经锁定的输入。

AI只观察当前公开可见的气球，选择没有炸弹且奖励最高的一列。没有安全奖励列时等待，不查看未来RNG或预取生成结果。其他席用同一输入与计时接口自动完成，不直接生成随机现金。

## 状态、存档和单次派奖

模块提供 `enter/start/tick/ai_step/next_player/settle_others/close/state_error`、`shoot/ai_lane`。路格、到访去重、小游戏分发和统一界面由 `minigame_rules.gd` 接入。

`pending_service.game`共有字段是 `id/version/player/tick/score/status/reason/reward/participants/cursor/history`，专属字段为：

| 字段 | 含义 |
|---|---|
| balloons | 可见气球数组，每项为整数lane、字符串kind、整数height/speed |
| choice | -1等待或0–3已锁定射击列 |
| events | 每拍的射击列及新生物品记录；结束拍spawn必须为空 |

状态校验从空球场完整重演events，重建当前气球、高度、速度、分数和结束原因；不只检查数值是否在范围内。历史席也逐一重演，验证收款人顺序和奖励。禁止结束后追加事件、结束拍伪造新生、修改现有气球位置/速度、浮点伪装整数、提前伪造奖励、替换历史收款人。

准备、进行、单席结果和全席结果均可保存；恢复后保留已锁定射击和随机序列。`close()`仅在全席结果可调用，逐席发放历史记录中的奖励，随后清空服务并回到land；重复确认被拒绝。同一棋盘行动的到访记录仍存在，不能关闭后立刻重开同一格刷奖。

## 验证

Godot 4.6.2命令行执行 `tests/shoot_balloons_test.gd`，结果 `SHOOT_BALLOONS_TEST failures=0`，日志 `.godot/r15-shoot-balloons-test.log`。测试包括：

- 同列币与元宝一起命中，其他列继续移动；混合炸弹列的明确测试优先级。
- 炸弹比奖励先飞出；AI避弹与等待，读取AI选择不会消耗随机数。
- 正常时限及提前命中炸弹均不多生成一拍。
- 快速重复点击、非法列、其他小游戏命令、重复派奖被拒绝。
- 准备、锁定射击、进行中、多物同列、提前结果、自动席接续、全席结果的存档恢复及相同随机续演。
- 26类非法字段、记录与浮点类型变体被拒绝，输入和现有对局不被修改。

完整测试执行无脚本错误。真实界面点击/暂停/存档与整局回归由本轮主集成验收记录覆盖。
