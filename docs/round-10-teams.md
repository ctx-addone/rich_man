# 第10轮：传统模式自由组队

本轮把“每席独立角色”扩展为自由组队，保留各自现金、存款、股票、卡牌和地产。依据及证据等级见 同目录《组队规则补证》（本地 `docs/research/r11-teams.md`） 和 经济研究（本地 `docs/research/r11-economy-specials.md`）。本轮没有新增挑战模式、领主技能或难度档位。

## 阵营配置与接口

`setup(names, seed, rounds, {"teams":[0,0,1,1]})` 开启2对2；`[0,1,0,2]` 为2对1对1；`[0,1,2,3]` 为原本各自为战。2～4名玩家的队伍编号可为0～3，不必连续。至少存在两个非空阵营。未传 `teams` 时每名玩家的 `p.team` 都设为自己的序号。

`Game.Teams.valid_assignment(value, player_count)` 可供菜单预检：只接受长度匹配、非布尔整数0～3的数组和至少两个阵营。错误配置不会部分赋值或悄悄合队；整个数组退回独立阵营并记日志。正式游戏 `p.team` 始终使用整数；`same_team` 兼容旧内存测试中的非空字符串队名，但新开局不会生成该格式。

| 接口 | 返回值 |
| --- | --- |
| `same_team(player_a, player_b)` | 两名有效席位是否同阵营；自己属于同队，非法索引为false |
| `is_opponent(player_a, player_b)` | 两名有效席位是否不同阵营；不替调用者判断卡牌范围或存活资格 |
| `team_members(team_id, include_bankrupt=true)` | 该整数阵营的席位序号数组 |
| `team_scores()` | `{team_id: 团队净资产}`，只列仍有未破产成员的队伍 |
| `active_teams()` | 仍有未破产成员的整数阵营编号数组 |
| `can_upgrade_property(lot_id)` | 当前阶段、位置、资金与状态是否允许本人或队友加盖 |

## 胜负与独立账本

官方明确队伍为胜负单位：仅剩一个未破产队伍即获胜；回合上限到达时比较团队资产。一个队员破产后，仍有存活队员的队伍继续比赛，不要求剩余队友互相淘汰。

当前集中列入 `TeamRules.TEST_PROFILE` 的待核实裁决：

- 团队分数为未破产成员个人 `net_worth` 之和，沿用当前现金、存款、股票市值与地产估值模型。
- 破产队员不再贡献分数；胜者数组 `winners` 列出胜队所有席位，包括先破产的队员。破产队员最终是否显示为原作胜者尚未核定。
- 资产相同的队伍并列获胜。只有一支存活队伍时不与已全员破产的队伍残留数据比较。
- 资金、卡牌、地产不自动共享，不从队友账户补款，也不因组队新增继承、转移地契、自动代偿或复活。破产清偿沿用已有测试规则。

默认独立阵营下，结果与之前个人胜负一致。乐透在到期边界发奖后仍参与最终净资产比较。

## 队友地产与协助加盖

同队地产免租。友方商业中心不进入收费转盘，友方酒店不收费或强制留宿。敌方地产继续原有支付、防御和酒店流程。

到访队友可替已有普通或大型建筑加盖：付款者是当前行动者，产权仍属于原地主。原作官方支持帮队友升级，PC社区攻略进一步明确队友花钱帮建；具体加盖费用、折扣与资格仍沿当前测试配置。资金不足整笔拒绝，不向地主或其他队友取钱。

每次加盖消耗本次落地操作，遵守当前最高等级；行动者梦游或受衰神限制时拒绝。衰神究竟看行动者还是地主尚无证据，当前保留行动者判断。队友协助不扩展成改建、选择研究、领取研究卡或从有主空地选建筑的权限；这些仍由地主控制。

同队书店会向离店角色赠卡，原地主不同时收一份；等级概率和卡片数量沿现有测试值。能源中心停留收入仍只给地主，队友是否可领缺乏证据。地产公司减租和能源中心加价由建筑、商店模型按己方/敌方分别处理；房屋同街与连锁数量仍按原地主统计，未擅自扩大为全队产权池。

## 卡牌与队伍关系

团队关系不是全局友伤开关。乌龟、停留、拾取及资金调配等卡已有队友用途的研究证据；路面道具与范围爆炸仍可能误伤本人或队友。全体敌方牌、指定角色牌、己方地产牌与街道牌分别核对。角色天赋和AI通过同一 `same_team` / `is_opponent` 接口识别关系，具体目标集合由各卡规则控制。

本轮将财神/穷神入场的对手集合限定为敌队，土地公只夺敌方产权，福神可给同队地产加盖。这是对现有“己方/对手”文字的集合解释，逐个神仙的队伍实机仍待核验，不能视为已确认全部神仙例外。

## 验证

`tests/teams_test.gd` 覆盖默认FFA、非法配置原子回退、非连续编号、身份接口、队友免租、酒店与商业产权、普通/大型帮建、付款人/产权、现金不足和恰好够用、最高等级/衰神/梦游、地主专属操作、团队书店、资产合计、并列、队友先破产、最后存活队伍、真实回合上限，以及2对2、2对1对1、3对1和FFA各一场30轮完整对局。原有核心及人物/建筑回归继续运行。

未宣称完成的原作细则包括团队精确资产估值、破产后乞丐行为、继承、全队连锁叠加、所有卡牌的团队资格矩阵、不同模式的特殊例外。
