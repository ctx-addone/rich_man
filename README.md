# 街区大亨 · 热座原型

> 2026-11-08：正在按[《大富翁11》2D还原目标](docs/r11-target.md)重建。下文描述已推送的v0.1通用原型，不能据此声称还原《大富翁11》。道路与建筑耦合、特殊设施等缺口见新的研究与对照记录。

Godot 4.6 的原创地产棋盘玩法原型。四个无技能角色由真人在同一台电脑轮流操作，也可由一人操作全部角色测试。

## 启动

Windows 双击 `start_game.cmd`。脚本先导入资源，再启动游戏；默认使用本机 `D:/software/Godot/4.6.2/Godot_v4.6.2-stable_win64.exe`。其他安装位置可设置环境变量 `RICHMAN_GODOT_BIN` 为 Godot 4.6 可执行文件的完整路径。

也可在 Godot 4.6 中导入 `project.godot`，按 F5 运行。主场景为 `scenes/main.tscn`。无需联网登录或其他运行服务。

## 游玩

主菜单 → 唯一地图“市民街区” → 四个席位的名字与外观 → 选择 10/20/30 轮（默认 20）→ 开始。每次交接后确认由当前玩家操作。

- 掷骰前每回合可用一张卡：遥控骰子、免租卡、信号切换、奖金卡。
- 掷骰后自动前进，在路口选择方向。地图共 57 个节点，含 3 座地铁站与 2 组信号灯。
- 停在无主地产可买地，停在自己的地产可升级到 3 级，停在其他角色地产支付租金。
- 地铁最终落点可付 200 换乘；红灯无路可走时剩余步数作废，仍可结束回合。
- 现金不足时自动半价变卖地产，仍无力支付则破产。最后一位存活者获胜，或到达轮次上限比较净资产；最高净资产相同者并列获胜。
- 点击地图格子查看详情。菜单内有玩法说明，对局侧栏有行动反馈和日志。

## GM 测试

对局中按 **F1** 或点击 **GM · F1**。支持指定下一次骰子 1～6、加减指定角色现金、发放卡牌、传送到任意有效节点和强制结算。使用后显示 GM 测试局标识。

传送当前玩家会停止移动并触发落点；传送非当前玩家只改位置。传送起点不领取经过收入。GM 减钱最低到 0，需通过实际支出触发破产。已结束比赛不再接受正常 GM 改局操作。

## 验证

在项目目录执行（Godot 路径可替换为本机安装）：

```powershell
& 'D:/software/Godot/4.6.2/Godot_v4.6.2-stable_win64_console.exe' --headless --path . --script tests/core_test.gd
```

已通过 50 个固定种子的完整 20 轮及关键经济/破产边界测试。真实引擎 UI 测试与无 GM 的完整自然结算证据见 [验收文档](docs/05-GM与验收.md)、[复跑说明与截图](docs/testing/README.md)、[UI 日志](docs/ui-test.log) 和 [完整单局日志](docs/full-ui-match.log)。
